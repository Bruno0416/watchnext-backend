# Reglas del Proyecto

### Regla: Uso del comando `zeditor` para abrir el editor Zed
Cuando se requiera o se solicite abrir archivos en el editor Zed desde la terminal, utiliza siempre el comando `zeditor` en lugar de `zed`. El comando `zed` es exclusivo de `zsh` en este entorno y fallará en `bash`.
